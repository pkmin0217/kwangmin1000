# Health Diet Recommendation Site

A clean, modern, and responsive web application that provides personalized diet recommendations based on your health goals and dietary preferences.

## Features

- **Personalized Recommendations:** Get tailored meal plans for breakfast, lunch, dinner, and snacks.
- **Goal-Oriented:** Supports Weight Loss, Muscle Gain, and Maintenance goals.
- **Dietary Preferences:** Includes options for None, Vegetarian, Vegan, and Gluten-Free diets.
- **Dark Mode:** A toggleable dark theme for comfortable viewing in low-light environments.
- **Responsive Design:** Optimized for both desktop and mobile devices.
- **Persistent Settings:** Your theme preference is saved automatically.

## How to Use

1. Open `index.html` in your web browser.
2. Select your "Health Goal" from the dropdown.
3. Select your "Dietary Preference" from the dropdown.
4. Click "Get Recommendation".
5. Use the 🌓 icon in the header to toggle between Light and Dark modes.

## Technologies Used

- HTML5
- CSS3 (Custom Properties / Variables)
- Vanilla JavaScript (ES6+)

## Project Structure

- `index.html`: The main structure and UI of the application.
- `style.css`: Modern styling with a "healthy and energetic" green theme and dark mode support.
- `main.js`: Core logic for diet recommendations and theme management.
- `blueprint.md`: The original project design document.
